# Orbit Browser

Orbit Browser is a desktop web browser built with Electron and Chromium. It is made to be simple to use, fast to open, and easier to browse with fewer distractions.

## What it does

Orbit Browser gives you a normal browser window with its own tabs, navigation buttons, search bar, bookmarks, history, and download view. It also includes a built-in shield that helps block ads and trackers.

## Main features

- Tabbed browsing so you can open many pages at once.
- Incognito tabs for private browsing sessions.
- Built-in ad blocking to reduce ads and tracking on websites.
- Shield view that shows how many items were blocked on the current page and across the whole browser.
- Bookmarks bar and bookmark manager for saving pages you want to keep.
- History panel to revisit pages you opened before.
- Downloads panel to see downloaded files.
- New tab page with a clock, greeting, search box, and quick settings.
- Search engine choice with Google, DuckDuckGo, or Bing.
- Reader mode for a cleaner reading view.
- Immersive mode to focus on the page.
- Compact header option to hide the browser bars when you want more space.
- Window controls for minimize, maximize, and close.

## How to run it

1. Install the project dependencies:

```bash
npm install
```

2. Start the browser:

```bash
npm start
```

If you are on Windows, you can also use `Start Orbit.bat`.

## Build for Windows

Create a packaged Windows version with:

```bash
npm run build
```

The built files are placed in the `dist` folder on your computer.

You do not need to upload `dist` to GitHub. Keep the source files in the repo and build the app on your own machine when needed.
